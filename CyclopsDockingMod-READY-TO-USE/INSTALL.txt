2. Click "Install Mod" (top toolbar)

MANUAL INSTALLATION (BepInEx)
═══════════════════════════════════════════════════════════════════

If installing manually:

1. Navigate to your Subnautica folder:
   C:\Program Files (x86)\Steam\steamapps\common\Subnautica\

2. Copy the "BepInEx" folder from this directory into your 
   Subnautica installation (merge with existing folder)

3. Copy the "Assets" folder into your Subnautica installation root

4. Launch Subnautica - the mod will load automatically
