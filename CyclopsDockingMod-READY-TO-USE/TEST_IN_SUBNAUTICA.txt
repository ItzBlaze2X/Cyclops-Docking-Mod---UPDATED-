INSTALLATION METHOD 1: Using Subnautica Mod Manager (EASIEST)
═══════════════════════════════════════════════════════════════════════════════

1. Open Subnautica Mod Manager (SMM)

2. Click the folder icon at the bottom-left (Open Mods Folder)
   This opens your BepInEx\plugins folder

3. Drag this entire folder into SMM:
   CyclopsDockingMod-READY-TO-USE

   Or copy the contents manually:
   - Copy: CyclopsDockingMod-READY-TO-USE\BepInEx\*
   - Paste into: [Your Subnautica Game]\BepInEx\

4. Restart Subnautica

5. Check the console for these messages:
   ✅ "CyclopsDockingMod loaded successfully"
   ✅ No "Ingredients not found" error

═══════════════════════════════════════════════════════════════════════════════
INSTALLATION METHOD 2: Manual Installation
═══════════════════════════════════════════════════════════════════════════════

1. Find your Subnautica game folder:
   Default: C:\Program Files (x86)\Steam\steamapps\common\Subnautica

2. Navigate to: BepInEx\plugins

3. Create a folder called: CyclopsDockingMod

4. Copy these files INTO that folder:
   FROM: CyclopsDockingMod-READY-TO-USE\BepInEx\plugins\CyclopsDockingMod\*
   TO:   [Subnautica]\BepInEx\plugins\CyclopsDockingMod\

5. Also copy the Assets folder:
   FROM: CyclopsDockingMod-READY-TO-USE\Assets\*
   TO:   [Subnautica]\BepInEx\plugins\CyclopsDockingMod\Assets\

6. Restart Subnautica
