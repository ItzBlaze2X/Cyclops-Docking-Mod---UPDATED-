═══════════════════════════════════════════════════════════════════════════════

⚠️  WHY GITHUB ACTIONS?

Local build environment has incompatibilities. GitHub Actions provides a clean,
pre-configured Windows environment with all required .NET SDKs and frameworks.

The exact same code that fails locally will build successfully on GitHub Actions.

STEP 4: CREATE THE BUILD WORKFLOW FILE
═══════════════════════════════════════════════════════════════════════════════

1. On GitHub, in your repository, click "Add file" → "Create new file"

2. In the filename box, type:
   .github/workflows/build.yml

3. Copy and paste this entire content into the file:

───────────────────────────────────────────────────────────────────────────────
name: Build CyclopsDockingMod

on: [push, pull_request, workflow_dispatch]

jobs:
  build:
    runs-on: windows-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup .NET
      uses: actions/setup-dotnet@v3
      with:
        dotnet-version: '6.0.x'
    
    - name: Restore dependencies
      run: dotnet restore "CyclopsDockingMod/CyclopsDockingMod.csproj"
    
    - name: Build Release
      run: dotnet build "CyclopsDockingMod/CyclopsDockingMod.csproj" -c Release --no-restore
    
    - name: Upload DLL
      uses: actions/upload-artifact@v3
      with:
        name: CyclopsDockingMod
        path: CyclopsDockingMod/bin/Release/CyclopsDockingMod.dll
        retention-days: 30

───────────────────────────────────────────────────────────────────────────────

4. Click "Commit new file" at the bottom

5. GitHub will automatically start the build! (You'll see a yellow dot next to
   the filename that turns green when done)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ Build fails on GitHub Actions:
   • Check the Actions tab → click the failed build
   • Scroll down to see the error message
   • The error will tell you what's wrong
   • Report the error and I can help fix it

❌ DLL doesn't appear in artifacts:
   • Make sure your source code is in a "CyclopsDockingMod" folder
   • The workflow expects: CyclopsDockingMod/CyclopsDockingMod.csproj
   • If your structure is different, let me know and I'll adjust the workflow

❌ Mod still gives "Ingredients" error:
   • Make sure you copied the NEW DLL (not the old one)
   • Check the modification date - should be today
   • Restart Subnautica completely
   • Check console for other error messages
