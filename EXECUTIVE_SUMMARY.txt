================================================================================
THE PROBLEM
================================================================================

Error Message:
  "Field 'Nautilus.Crafting.RecipeData.Ingredients' not found."

Root Cause:
  Incorrect type aliasing in CyclopsHatchConnector.cs caused the Nautilus build
  to reference the wrong Ingredient type (SMLHelper instead of Nautilus).

Impact:
  Mod fails to initialize when Nautilus 1.0.0.53+ is installed.

================================================================================
THE SOLUTION
================================================================================

File Modified: CyclopsDockingMod/CyclopsHatchConnector.cs

Change:
  Moved the line "using Ingredient = CraftData.Ingredient;" from global scope
  into the #else conditional block so it only applies to SMLHelper builds.

Fix:
  ❌ BEFORE (lines 1-11):
     #if SUBNAUTICA_NAUTI
       using Nautilus.Crafting;
     #else
       using SMLHelper.V2.Crafting;
     #endif
     using Ingredient = CraftData.Ingredient;  // WRONG: affects both branches

  ✅ AFTER (lines 1-12):
     #if SUBNAUTICA_NAUTI
       using Nautilus.Crafting;
     #else
       using SMLHelper.V2.Crafting;
       using Ingredient = CraftData.Ingredient;  // CORRECT: only for SMLHelper
     #endif

Result:
  ✅ Nautilus builds use Nautilus.Crafting.Ingredient
  ✅ SMLHelper builds use CraftData.Ingredient
  ✅ RecipeData API works correctly for both
